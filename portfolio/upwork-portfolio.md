# Upwork portfolio copy

## Project title

MetricFlow | Next.js SaaS Dashboard & Customer Management

## My role

Frontend Developer & UI Designer

## Project description

I designed and built MetricFlow, an interactive SaaS dashboard for revenue analytics, customer management, subscriptions, and billing. I handled the visual system, responsive React implementation, accessible interactions, data modeling, and deployment. Built with Next.js, TypeScript, Tailwind CSS, and Radix UI. The result is a six-page demo with searchable tables, editable customers, CSV exports, persistent settings, and light/dark themes. This is a portfolio concept using fictional data, not a live client business.

## Skills and deliverables

React · Next.js · TypeScript · Tailwind CSS · Responsive Design

## Detailed case study

### Project overview

MetricFlow is a SaaS operations dashboard concept that helps a subscription business see its performance and manage customer relationships in one workspace. The interface pairs a restrained violet palette with clear typography, compact data tables, and responsive charts.

### What I was responsible for

- Product structure and page flows across six dashboard sections.
- Visual design, reusable components, and light/dark theme tokens.
- Next.js App Router architecture and TypeScript implementation.
- Customer search, filtering, sorting, pagination, selection, creation, and editing.
- Subscription management, invoice details, and safe CSV exports.
- Accessible dialogs, keyboard search, mobile navigation, and form validation.
- Browser persistence, responsive verification, documentation, and release preparation.

### Technologies

Next.js 16, React 19, TypeScript, Tailwind CSS 4, Radix UI, shadcn/ui-style components, Lucide, next-themes, custom SVG charts, and locally hosted Inter Variable fonts.

### Project results

- Six complete, connected dashboard pages.
- Twenty-four editable fictional customer accounts and eighteen historical sample invoices.
- Three reporting periods with revenue totals that match chart exports.
- Responsive layouts for desktop, tablet, and mobile.
- Persistent customer changes and workspace preferences, with a demo reset flow.
- A documented frontend project that can be extended with real APIs and billing services.

These are implementation outcomes. Revenue, subscribers, conversion, and growth shown in the interface are fictional demonstration metrics, not business results achieved for a client.
